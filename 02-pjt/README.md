# 도서 데이터 수집과 AI 분류

알라딘 도서 검색 API로 주제별 도서를 모아 통계를 내고, 생성형 AI로 분류한 뒤 책 소개를 음성 파일로 만든 SSAFY 2회차 관통 프로젝트다.

- 기간: 2026.07.28 ~ 2026.09.04
- 인원: 개인
- 기술: Python, requests, OpenAI API (SSAFY GMS, `gpt-5-nano`), gTTS

## 주요 기능

- 주제별 도서 수집과 평균 가격·출간 연도 통계 (B1)
- 할인 도서와 정가 도서를 나눠 JSON으로 저장 (B2)
- 한국문학, 음악 도서의 소개를 mp3로 변환 (B3, C3)
- 도서 100권을 여러 번 나눠 받아 가격순 상위 10권 저장 (C1)
- GPT로 독서 관련 도서를 습관, 시간관리, 독서법, 기타로 분류 (C2)

결과물은 `output/` 폴더에 생긴다.

## 고민한 점

### 한 번에 50권까지만 오는 API

100권이 필요했는데 알라딘 API는 한 번에 최대 50권만 돌려준다. `start` 값을 1, 2로 올려 가며 여러 번 요청하고 결과를 이어 붙이는 방식으로 해결했다. 이후 다른 문제에서도 같은 함수를 재사용했다.

### GPT 응답이 빈 문자열로 오는 문제

도서 100권을 "카테고리: [제목 목록]" 형태로 한 번에 분류해 달라고 했더니 응답이 비어서 왔다. `usage`를 찍어 보니 reasoning 토큰이 `max_completion_tokens` 16000을 전부 써 버려서 실제 답을 쓸 토큰이 남지 않은 것이었다. 응답 형식을 "번호: 카테고리"로 훨씬 가볍게 바꾸고, 묶는 작업은 파이썬에서 하도록 바꿨더니 정상적으로 왔다.

### 형식이 제각각인 출간일

`pubDate`는 `"2025-06-27"` 같은 문자열이라 앞 네 자리를 연도로 잘라 썼는데, 값이 비어 있는 책이 있어서 평균 계산에서 에러가 났다. `isdigit()`으로 숫자인지 확인한 책만 계산에 넣었다.

## 실행 방법

```bash
pip install -r requirements.txt
cp .env.example .env   # MY_TTBKEY(알라딘), MY_API_KEY(SSAFY GMS) 입력
python problem_B1.py
```

## 배운 점

- `.env`와 `python-dotenv`로 API 키를 코드 밖에 두는 방법을 익혔다.
- API 문서를 읽고 `QueryType`, `MaxResults`, `start` 같은 파라미터를 직접 찾아 요청을 짜 봤다. 라이브러리 사용법을 아는 것과 실제 응답을 서비스에 맞게 가공하는 건 다른 문제라는 걸 느꼈다.
- `gpt-5-nano`는 `temperature`를 기본값 말고 다른 값으로 주면 400 에러가 난다. 모델마다 지원하는 파라미터가 다르다.
- `gTTS`를 설치하다가 다른 패키지 버전이 바뀌어 충돌이 났다. 프로젝트마다 가상환경을 따로 써야 하는 이유를 직접 겪었다.
