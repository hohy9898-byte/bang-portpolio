About

소개

SSAFY에서 웹 개발을 공부하고 있습니다. 팀 프로젝트 「부산, 축제 어디까지 가는 거예요?」에서 조장을 맡아 일정과 기능 범위를 조율하고, 커뮤니티 게시판 전체를 Vue 3로 구현했습니다.

기능을 만드는 것에서 끝내지 않고, 배포한 뒤에 발견한 문제도 직접 고칩니다. 브라우저에 노출되던 API 키를 서버리스 함수로 옮기고, 챗봇 프롬프트에 들어가는 데이터를 줄여 응답 속도를 개선한 경험이 있습니다.
